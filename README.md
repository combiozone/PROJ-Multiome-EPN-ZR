### Data availability
Raw and processed snMultiome sequencing files, including Cell Ranger ARC outputs such as .h5 feature-barcode matrices and ATAC fragment files, are available through GEO under the following accession numbers:

[GSE269937](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE269937), [GSE314803](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE314803), [GSE314599](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE314599), and [GSE314911](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE314911).

The integrated snMultiome Seurat object used in this study is available through Zenodo:

https://doi.org/10.5281/zenodo.20818179
